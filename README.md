# Clawdia Landing Page

Landing page estática de alta conversão para a Clawdia — secretária pessoal via IA no WhatsApp.

## Observação técnica

O formulário de WhatsApp está pronto no front-end, mas ainda não está conectado a backend/API/CRM/WhatsApp Business. Para capturar leads de verdade, configurar uma das opções:

- endpoint próprio de API;
- ferramenta de formulário/CRM;
- número oficial de WhatsApp Business com link `wa.me`;
- webhook/serverless function.
